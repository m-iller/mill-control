# История изменений

## [0.2.0] - 2026-11-15

### Добавлено

- Формулы показываются в математической записи: дроби, степени, корни, индексы, греческие буквы, кусочные формулы со скобкой. Запись обновляется при наборе.
- Страница «Все формулы» со значениями при текущем режиме и сохранением в PNG.
- Плитки с главными показателями на вкладке «Расчёт»: выпуск, производительность, первый отказ, момент капремонта, число узлов в окне.
- Подсветка текста формулы.

### Изменено

- Единое светлое оформление окна, группировка полей, таблицы с выравниванием чисел. Числа показываются без записи вида `1.487e+04`.
- В дереве модели рядом с именем видно описание, значение параметра и текст формулы.
- Экспорт CSV пишет исходные числа, а не округлённые подписи.

### Исправлено

- Калибровка не сдвигала большие коэффициенты (`N0` порядка 10⁷ оставался прежним, хотя сообщалось об успехе) и неточно подгоняла `L0_ins`. Теперь подгоняется логарифм отношения к текущему значению.
- Калибровка сообщала об успехе, когда `least_squares` не сошёлся.
- Калибровка принимала замену детали (рост толщины между замерами) за отрицательный износ.
- На вкладке «Модель» нельзя было сохранить значение параметра: поля комментария и кнопка сохранения были отключены.

## [0.1.0] - 2026-11-13

### Добавлено

- Расчёт остаточного ресурса, времени до гарантированного отказа и вероятности безотказной работы узлов барабанной шаровой мельницы.
- Формулы, параметры и узлы хранятся в базе и правятся из окна. Версии формул сохраняются, их можно сравнить и откатить.
- Подбор режима, момента капитального ремонта и кратностей замены.
- Замеры и журнал режима, калибровка коэффициента износа по истории замеров.
- Модель по умолчанию для мельницы класса МШЦ 3.6×5.5 с условными коэффициентами.
- Экспорт и импорт модели в JSON.
- Сборка `.deb` и сценарии локального выпуска релиза. Тесты в GitHub Actions не запускаются.
